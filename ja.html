Features

モダンなアプリケーションを簡単に構築し、開発プロセスを迅速に開始

先進的な技術スタック

効率的な React (v19) フレームワーク、Next.js、Nextra(v4)、Shadcn UIを使用してモダンなアプリケーションを構築

国際化サポート (i18n)

多言語サポートを内蔵し、アプリケーションの国際化を簡単に実現し、ユーザー層を拡大

TypeScript 型安全

TypeScriptを完全に統合し、静的型チェックを提供し、ランタイムエラーを減らし、コードの信頼性と保守性を向上

Iconify アイコンセット

純CSSアイコン、Iconifyアイコンセットを統合し、豊富なアイコン選択を提供し、UIの視覚表現を強化

Tailwind CSS (v4)

原子化CSSフレームワークTailwind CSSを使用し、効率的なデザインとレスポンシブUIを迅速に構築

コード規範

ベストプラクティスに従ったコード規範を採用し、ESLintを組み合わせてコード品質のチェックと一貫性を維持

ダークモード

ダークモードをサポートし、夜間の使用体験を向上

豊富なコンポーネントと自由な拡張サポート

豊富なプリセットコンポーネントを提供し、柔軟なカスタム拡張をサポート

軽量設計
