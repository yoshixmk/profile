# 簡単な紹介

## 自己紹介

モダンなWeb技術に精通し、スケーラブルで高性能なアプリケーションの構築に情熱を注ぐフルスタック開発者です。TypeScript、React、Next.js、クラウドインフラストラクチャの経験があります。

## 技術スタック

### フロントエンド
- **フレームワーク**: Next.js 15、React、Vue 3
- **スタイリング**: Tailwind CSS 4、SASS、PostCSS
- **アニメーション**: Framer Motion、tsparticles
- **UIライブラリ**: shadcn/ui、Radix UI

### バックエンド & ランタイム
- **ランタイム**: Node.js、Deno
- **言語**: TypeScript、JavaScript、Rust（学習中）
- **データベース**: Firestore、MongoDB、PostgreSQL

### ツール & DevOps
- **ビルドツール**: Vite、Webpack、pnpm
- **テスト**: Jest、Playwright、Vitest
- **CI/CD**: GitHub Actions、Netlify
- **バージョン管理**: Git、GitHub

## 現在の取り組み

現在取り組んでいること:
- Next.jsとNextraを使用したモダンなWebアプリケーションの構築
- Denoエコシステムの探索とオープンソースプロジェクトへの貢献
- インタラクティブなドキュメントとブログプラットフォームの開発
- 堅牢なソフトウェアのためのプロパティベーステストの実装

## オープンソース貢献

以下を含む様々なオープンソースプロジェクトへの積極的な貢献者:
- Denoサードパーティモジュール
- 技術ドキュメントの日本語翻訳
- Webフレームワークとツール
