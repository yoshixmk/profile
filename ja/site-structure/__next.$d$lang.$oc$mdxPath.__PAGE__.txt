# 🛠️ このサイトの構成

コアフレームワークの重要なアップグレードが完了し、より良い開発体験をお届けします！

<Callout emoji={<span className='icon-[ri--alarm-warning-fill]'></span>} type="info">
注意

このバージョンは最新のリリースバージョンです。テスト済みですが、まだ発見されていない問題が存在する可能性があります。異常や不安定な状況に遭遇した場合は、すぐに[フィードバック](https://github.com/pdsuwwz/nextjs-nextra-starter/issues)をお願いします。できるだけ早く修正します。

### Nextra v4 更新ポイント

Nextra v4 がリリースされ、多くの重要な改善と新機能が導入されました：

- 🚀 **App Router サポート**：Next.js App Routerへの完全移行、Pages Routerの廃止、最新のMetadata APIのサポート。
- ⚡ **より高速なページ読み込み**：最適化されたバンドルサイズとパフォーマンスにより、ウェブサイトの応答がより迅速に。
- 🔍 **新しい検索エンジン**：Rustベースの Pagefind が、より正確で効率的な検索体験を提供。
- 🏎️ **Turbopack サポート**：開発体験の向上、長期的なコミュニティのニーズに対応。
- 🌍 **RSC + i18n**：国際化サポートの強化、多言語ウェブサイト開発の簡素化。
- 🎨 **最適化されたテーマスタイル**：UIデザインの改善、視覚的一貫性の強化。
- 📱 **より良いモバイル対応**：小画面デバイス向けの表示効果とインタラクション体験の最適化。
- 📚 **より強力なディレクトリ構造**：新しい「Page Map」がmd/mdxとapp/ディレクトリ内のjsx/tsxページの収集をサポート。
- 🛠️ **リモートMDXレンダリング**：任意のコンテンツソースからMDXを読み込み、サイドバーナビゲーションを正確に生成。
- ✨ **強化された目次（TOC）**：Markdownの見出しを正確に表示し、JSX、コードブロック、数式などのコンテンツをサポート。

詳細については、[Nextra v4 公式アップグレードガイド](https://the-guild.dev/blog/nextra-4)を参照してください。

### Tailwind CSS v4 更新ポイント

Tailwind CSS v4 が正式にリリースされ、複数の重要な改善と新機能が導入されました：

- 🚀 **新しい高性能エンジン**：完全ビルドの速度が最大5倍向上、増分ビルドの速度が100倍以上向上し、単位はマイクロ秒。
- 💎 **現代のWeb設計向け**：カスケードレイヤー（cascade layers）、`@property`を使用したカスタムプロパティ、`color-mix()`などの最先端のCSS機能に基づいて構築。
- 🎯 **インストールプロセスの簡素化**：依存関係の削減、ゼロ設定、CSSファイルに1行追加するだけ。
- 📦 **公式Viteプラグイン**：緊密な統合、パフォーマンスの最大化と設定の最小化。
- 🔍 **自動コンテンツ検出**：すべてのテンプレートファイルを自動的に検出、設定不要。
- 📂 **組み込みインポートサポート**：追加ツールなしで複数のCSSファイルをバンドル。
- 🛠️ **CSS優先設定**：開発者体験の再考、tailwind.config設定ファイルなしで、CSS内で直接フレームワークをカスタマイズおよび拡張。

詳細については、[Tailwind CSS v4 アップグレードガイド](https://tailwindcss.com/docs/upgrade-guide)と[公式ブログ](https://tailwindcss.com/blog/tailwindcss-v4)を参照してください。


### 移行手順

スムーズなアップグレードを確保するために、以下をお勧めします：

1. まずテスト環境でアップグレードの検証を行う
2. カスタムコンポーネントの互換性を確認する
3. コンソールに警告メッセージがないか確認する
4. 公式移行ガイドに従って段階的に操作する
