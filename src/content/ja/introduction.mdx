# 簡単な紹介

Next.js + Nextra + TypeScript + Tailwind CSSを採用した無料でオープンソース、そして強力なテンプレート

```js
console.log('hello, world')
```

## インストールと実行

* 依存関係のインストール

```bash
pnpm install
```

* ローカル開発

```bash
pnpm run dev
```
